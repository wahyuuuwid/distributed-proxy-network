Distributed Proxy Network Simulator

Sebuah implementasi sistem server terdistribusi berbasis Python untuk mengoptimalkan rute data, manajemen beban trafik, dan keamanan jaringan lokal.

Jelajahi Fitur Buka Live Console

Arsitektur Jaringan

Komponen utama yang menyusun sistem server proksi terdistribusi ini.

Web Server

Melayani request HTTP dari client dan menyajikan aset statis seperti HTML, CSS, dan media dengan efisien.

Proxy Node

Bertindak sebagai perantara cerdas untuk meneruskan request, menyembunyikan identitas asli client, dan melakukan caching data.

Distributed Client

Simulasi beberapa request client yang berjalan secara simultan untuk menguji ketahanan topologi jaringan.
